## 巡检结论

PRD 与原型已按最终业务规则完成统一，核心演示闭环可运行。桌面端、移动端页面均保留现有太重数智视觉样式，没有新增与业务无关的工作台或菜单。

## 已确认的关键规则

- 风险从新建风险点开始；一个风险点包含多条危险源，每条危险源分别评价并填写措施，整个风险点统一提交审批。
- 重大、较大风险由二级单位领导审批；一般、低风险由工段或作业区负责人审批；平台管理员不得代办业务审批。
- 巡检计划按周期自动生成班组任务，首位符合权限的班组成员领取后锁定；班组长有因解锁或转交。
- 检查内容逐条生成检查项，是否必拍由检查标准逐条配置；不合格项逐条转隐患并保留来源。
- 集团专业检查只录入、查看同专业部门的已闭环检查台账；集团监督检查进入整改闭环并按规则同步 OA。
- 作业票超时后立即阻断，必须申请延期；延期批准并重新确认后才能继续作业。
- 铸锻件分公司使用造型作业区实际班组场景；智能加工配送中心保留独立风险和巡检最小样例。
- 直接打开首页时恢复初始演示数据，避免上次演示状态残留。
