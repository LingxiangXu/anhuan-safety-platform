# 安全管理平台相关方管理模块 PRD

版本：v1.0（相关方台账、人员证书、违章与黑名单，2026-08-31）  
适用范围：一期首批为铸锻件分公司、智能加工配送中心；后续按分子公司推广  
文档状态：业务规则基线

## 1. 模块定位

相关方管理是安全管理平台的独立模块，用于统一记录为各单位提供服务的外部公司、其现场人员、人员证书和人员违章情况。各分子公司维护本单位相关方数据；集团、公司安全管理人员可跨单位查看相关方和黑名单数据，用于安全监督与统计。

本模块一期聚焦“建档可查、人员证书可核、违章可记、三次自动标黑”的基础管理，不将黑名单与准入、作业票、门禁、合同或付款等外部业务联动。

## 2. 一期范围与边界

### 2.1 建设范围

1. 相关方台账：登记外部公司及其归属维护单位、服务范围、联系人、联系电话和合作状态。
2. 人员与证书：在相关方公司下维护现场人员；逐人维护证书名称、证书编号、有效期和证书附件。
3. 违章记录：登记相关方人员的违章时间、地点、违章内容和附件。
4. 黑名单：同一相关方人员累计达到 3 次违章后，系统自动标记为黑名单并形成可查询列表。
5. 权限：集团、公司安全管理人员可跨单位查看；各分子公司仅维护本单位相关方数据。

### 2.2 不在一期范围

1. 不建设公司资质、营业执照、合同、准入审批、评价评分或付款管理。
2. 黑名单仅作标记和查询，不限制人员登录、入场、作业票、门禁或其他系统操作。
3. 不建设黑名单解除、申诉、审批或处罚流程。
4. 不与特殊作业、巡检、隐患、门禁或外部承包商系统做自动数据联动。

## 3. 角色与数据权限

| 角色 | 可查看范围 | 可维护范围 |
|---|---|---|
| 集团安全管理人员 | 全部授权分子公司相关方、人员、证书、违章及黑名单 | 无跨单位维护权 |
| 公司安全管理人员 | 全部授权分子公司相关方、人员、证书、违章及黑名单 | 无跨单位维护权 |
| 分子公司安全管理人员 | 本单位相关方及下属组织数据 | 本单位数据 |
| 作业区负责人/班组长 | 按授权查看本单位相关方信息 | 是否允许维护由本单位角色配置决定 |
| 平台管理员 | 按平台配置查看，不因系统配置获得业务维护权 | 字典、参数等平台配置 |

跨单位查看不等于跨单位编辑、删除或代办。相关方公司、人员、证书和违章记录均以“维护单位”为数据归属依据。

## 4. 页面与交互设计

PC 端入口为左侧一级菜单“相关方管理”，进入后采用以下四个页签：

| 页签 | 页面内容 | 关键操作 |
|---|---|---|
| 相关方台账 | 公司名称、维护单位、服务范围、联系人、联系电话、合作状态、人员数、违章人数、更新时间 | 查询、新增、查看详情、编辑本单位台账 |
| 人员与证书 | 人员姓名、岗位/工种、所属相关方、当前状态、证书数量、证书有效期 | 新增人员、编辑人员、维护证书、上传图片或 PDF、查看附件 |
| 违章记录 | 违章人员、所属公司、维护单位、违章时间、地点、违章内容、累计次数、处理结果 | 查询、登记违章、查看附件 |
| 黑名单 | 已累计 3 次及以上违章的人员、所属公司、累计次数、最近违章时间、标记说明 | 查询、查看违章明细 |

新增和编辑使用居中业务弹窗，点击弹窗外区域不关闭；查看详情使用右侧抽屉，点击遮罩可关闭。所有成功操作后刷新当前页签数据并提示结果。

## 5. 业务规则

### 5.1 相关方台账

1. 新增相关方必须填写公司名称、维护单位、服务范围、联系人和联系电话。
2. 公司资质不是本模块字段，不展示也不校验公司资质。
3. 同一维护单位下，公司名称应唯一；如需维护同名公司，由维护人员先核实后编辑既有台账。
4. 合作状态仅用于台账展示，不触发人员、证书或黑名单状态变化。

### 5.2 人员与证书

1. 每名相关方人员必须关联一家公司，并填写姓名和岗位/工种。
2. 人员证书按人员维护；每张证书必须填写证书名称、证书编号、有效期，并上传证书图片或 PDF。
3. 可为一人维护多张证书；附件只保存为该证书的证明材料，不替代公司资质或培训记录。
4. 人员被自动标记为黑名单后，其人员资料、证书和历史违章仍可查看。

### 5.3 违章与黑名单

1. 违章登记必须关联具体相关方人员，并填写违章时间、地点和违章内容；违章附件可上传图片或 PDF 作为留存材料。
2. 系统按人员统计累计违章次数，不按公司合并计算。
3. 累计第 3 次违章登记成功后，系统立即将该人员状态更新为“黑名单”，并在黑名单页签显示“累计 3 次及以上违章，系统自动标记”。
4. 黑名单仅为平台标识，不自动限制该人员的任何业务操作，不触发审批、通知或外部系统调用。

### 5.4 业务流转

```text
分子公司维护相关方公司
        ↓
维护该公司现场人员
        ↓
逐人维护证书及图片/PDF 附件
        ↓
登记人员违章
        ↓
累计次数小于 3 次 ──→ 保持正常状态
        ↓ 达到第 3 次
系统自动标记黑名单 ──→ 集团/公司安全管理人员可跨单位查看
```

## 6. 数据与编号

| 对象 | 关键数据 | 编号规则 |
|---|---|---|
| 相关方公司 | 公司名称、维护单位、服务范围、联系人、联系电话、合作状态 | `PARTY-YYYY-NNN` |
| 相关方人员 | 公司、姓名、岗位/工种、手机号、人员状态 | 平台内部唯一标识 |
| 人员证书 | 人员、证书名称、证书编号、有效期、附件 | 使用证书法定编号；平台内部另设唯一标识 |
| 违章记录 | 人员、时间、地点、内容、附件、累计次数、处理结果 | `RPV-YYYY-NNN` |

所有新增、编辑、上传证书、登记违章和自动标黑动作均应留存操作人、操作时间、前后状态和附件信息。

## 7. 验收场景

| 编号 | 场景 | 验收结果 |
|---|---|---|
| AC-RP-01 | 分子公司新增本单位相关方公司 | 必填信息完整，台账仅在本单位维护范围内可编辑 |
| AC-RP-02 | 为相关方人员新增证书并上传图片/PDF | 证书保存人员、编号、有效期和附件，可在人员证书页查看 |
| AC-RP-03 | 连续登记同一人员 3 条违章 | 第 3 条保存后人员自动标记黑名单，黑名单页显示累计次数和最近违章 |
| AC-RP-04 | 集团或公司安全管理人员查看跨单位数据 | 可查看其他授权单位的相关方、证书、违章和黑名单，但不可编辑非本单位数据 |
| AC-RP-05 | 黑名单人员查看 | 页面仅展示标记和违章历史，不出现拦截、解除、审批或外部联动动作 |
