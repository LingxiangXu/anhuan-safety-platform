# 安全管理平台应急管理模块 PRD

版本：V1.0  
日期：2026年8月23日

## 1. 模块定位

应急管理用于统一维护现有应急预案，使现场和管理人员能够按预案类型、适用组织和关键词快速查询，并查看原始 PDF 文件及预案正文。模块重点是预案归集和查询，不扩展应急演练、应急物资、救援队伍、事故指挥或实时调度。

## 2. 一期范围

1. 应急预案目录分类；
2. PDF 预案上传和基本信息维护；
3. 按名称、类型、适用组织和状态查询；
4. 查看预案详情和原始文件；
5. 预案正文关键词检索和命中定位；
6. 预案更新、失效和历史版本查询。

## 3. 页面结构

应急管理在 PC 端作为独立一级菜单，进入后在页面左侧使用以下页签：

1. 应急预案；
2. 预案内容检索。

应急预案列表展示预案名称、类型、编号、编制单位、适用组织、发布日期/生效日期、当前版本、状态和操作。复杂信息通过新增/编辑弹窗和详情抽屉维护，不增加多层页面。

## 4. 核心流程

```text
管理员选择预案类型
→ 上传 PDF 并填写预案基本信息
→ 保存草稿
→ 发布为当前有效版本
→ 使用者按目录或关键词查询
→ 查看命中内容及原始 PDF
→ 预案修订时上传新版本
→ 新版本生效，旧版本进入历史
```

## 5. 页面字段

### 5.1 预案维护

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 预案名称 | 是 | 正式名称 |
| 预案类型 | 是 | 综合应急预案、专项应急预案、现场处置方案 |
| 预案编号 | 否 | 按现有制度编号 |
| 编制单位 | 是 | 预案责任组织 |
| 适用组织 | 是 | 可选择集团、股份公司或所属单位 |
| 发布日期 | 否 | 文件发布日期 |
| 生效日期 | 否 | 当前版本生效日期 |
| 状态 | 是 | 草稿、有效、失效 |
| 关键词 | 否 | 事故类型、装置、区域等检索词 |
| PDF 原文件 | 是 | 一期只接收 PDF |
| 版本说明 | 修订时必填 | 说明修订原因和主要变化 |

### 5.2 详情与检索

详情展示基本信息、适用范围、当前版本、历史版本、正文目录和原文件入口。检索结果展示预案名称、预案类型、命中章节/页码和命中摘要，点击后定位到相关内容。

## 6. 状态与权限

```text
草稿 → 有效 → 失效
有效预案修订 → 新版本草稿 → 发布 → 新版本有效，旧版本进入历史
```

- 应急管理人员：新增、编辑草稿、发布、失效和查看历史版本；
- 普通使用者：按组织权限查询和查看有效预案；
- 平台管理员：维护角色和数据范围，不默认代办预案发布；
- 只有草稿可删除，已发布预案只能失效或形成新版本。

## 7. 关键业务规则

1. 应急预案统一进入应急管理，不在安全知识库重复维护。
2. 使用者默认查看当前有效版本，历史版本只读。
3. 查询和全文检索必须先校验适用组织及数据权限。
4. 原始 PDF 是正式预案依据；解析正文只用于检索和定位。
5. 扫描版 PDF 无法解析时显示“暂不可全文检索”，不得伪造命中内容。
6. 一期不建设演练计划、演练记录、应急物资、队伍调度、报警联动和事故指挥。

## 8. 验收场景

| 编号 | 场景 | 预期结果 |
|---|---|---|
| AC-EM-01 | 上传专项应急预案并发布 | 预案在授权组织的有效列表展示，可查看原文件 |
| AC-EM-02 | 按预案类型和适用组织筛选 | 返回符合条件的预案，不泄露其他组织数据 |
| AC-EM-03 | 搜索预案正文关键词 | 返回命中摘要，点击可定位相关章节或页码 |
| AC-EM-04 | 修订已生效预案 | 新版本发布后成为当前有效版本，旧版本可追溯 |
| AC-EM-05 | 查看未授权预案 | 系统不展示或明确提示无权限 |

## 9. 当前实现边界

当前原型已提供应急预案列表和内容检索页面，可演示筛选、详情、原文件入口和命中定位反馈。真实文件上传、PDF 在线预览、OCR、正文索引、权限接口和版本持久化仍待生产建设。
