# 安全管理平台安全知识库模块 PRD

版本：V1.0  
日期：2026年8月23日

## 1. 模块定位

安全知识库用于统一管理与安全生产相关的法律法规和公司安全管理制度，解决文件分散、查找困难和现场引用不便的问题。用户可按目录分类浏览、查看原始 PDF 文件，也可输入关键词检索文件标题和已解析正文，并定位到命中内容。

本模块不包含应急预案，应急预案统一进入独立的“应急管理”模块；不建设智能问答、自动生成制度、在线编辑正文或复杂知识图谱。

## 2. 一期范围

| 分类 | 一期能力 | 说明 |
|---|---|---|
| 法律法规 | 分类、查询、检索、查看原文件 | 支持国家、行业及地方安全法规资料 |
| 安全制度 | 分类、查询、检索、查看原文件 | 支持集团、股份公司及所属单位制度资料 |
| 文件导入 | 上传 PDF、填写基本信息、发布 | 原文件作为正式查看依据 |
| 内容检索 | 标题/关键词检索、命中摘要、原文定位 | 依赖生产环境 PDF 解析或 OCR 服务 |
| 版本留痕 | 更新文件并保留历史版本 | 当前有效版本默认展示 |

## 3. 页面结构

安全知识库在 PC 端作为独立一级菜单，进入后在页面左侧使用以下页签：

1. 法律法规；
2. 安全制度；
3. 内容检索。

列表页统一采用“分类筛选 + 关键词 + 状态 + 查询/重置 + 文件列表”的布局。点击文件名称或“查看”进入详情抽屉，展示基本信息、目录、命中内容和“查看原文件”入口。

## 4. 核心流程

```text
管理员选择资料分类
→ 上传 PDF 并填写文件名称、文号、发布单位、生效日期、适用组织
→ 保存草稿
→ 发布为当前有效版本
→ 使用者按分类浏览或关键词检索
→ 查看命中摘要
→ 打开原始 PDF 核对全文
→ 文件更新时上传新版本并保留历史版本
```

## 5. 页面字段

### 5.1 文件维护

| 字段 | 必填 | 说明 |
|---|:---:|---|
| 资料分类 | 是 | 法律法规或安全制度 |
| 文件名称 | 是 | 文件正式名称 |
| 文号/制度编号 | 否 | 无编号时可为空 |
| 发布单位 | 是 | 法规发布机关或制度发布组织 |
| 生效日期 | 否 | 未正式生效时可为空 |
| 适用组织 | 是 | 集团、股份公司或指定所属单位 |
| 关键词 | 否 | 用于辅助检索，多个关键词分开维护 |
| 文件状态 | 是 | 草稿、有效、失效 |
| PDF 原文件 | 是 | 一期只接收 PDF |
| 版本说明 | 更新时必填 | 说明替换或更新原因 |

### 5.2 列表展示

文件名称、分类、文号/编号、发布单位、生效日期、适用组织、当前版本、状态、更新时间和操作。

### 5.3 内容检索结果

展示文件名称、分类、命中章节/页码、命中摘要和查看入口。打开结果后定位至对应内容附近，同时保留打开原始 PDF 的入口。

## 6. 状态与权限

```text
草稿 → 有效 → 失效
   └→ 删除（仅未发布草稿）
有效文件更新 → 新版本草稿 → 发布 → 新版本有效，原版本进入历史
```

- 知识库管理员：上传、编辑草稿、发布、失效和查看历史版本；
- 普通使用者：按组织权限浏览、检索和查看有效文件；
- 平台管理员：维护权限与目录配置，不默认代替知识库管理员发布内容；
- 已发布文件不得直接覆盖，更新必须形成新版本。

## 7. 关键业务规则

1. 应急预案不得混入安全知识库，统一在应急管理模块维护。
2. 使用者默认只看到当前有效版本，历史版本通过详情中的版本记录查看。
3. 检索结果必须受适用组织和数据权限限制，不得因全文检索扩大文件可见范围。
4. 原始 PDF 是正式文件依据；解析正文只用于检索和定位，不替代原文件。
5. 扫描版 PDF 无文本层时需通过 OCR 建立索引，识别失败应显示“暂不可全文检索”，但仍可查看原文件。
6. 一期不自动判断法规合规性，不生成制度内容，也不提供智能问答。

## 8. 验收场景

| 编号 | 场景 | 预期结果 |
|---|---|---|
| AC-KB-01 | 上传一份法律法规 PDF 并发布 | 文件出现在法律法规列表，状态为有效，可打开原文件 |
| AC-KB-02 | 上传一份安全制度并限定适用组织 | 仅授权组织用户可查询和查看 |
| AC-KB-03 | 输入正文关键词检索 | 返回命中文件和摘要，可进入详情定位命中内容 |
| AC-KB-04 | 更新已发布文件 | 生成新版本，发布后新版本生效，旧版本可追溯 |
| AC-KB-05 | 扫描版文件解析失败 | 明确提示暂不可全文检索，原始 PDF 仍可查看 |

## 9. 当前实现边界

当前原型已提供法律法规、安全制度和内容检索页面，可演示筛选、详情、原文件入口和命中定位反馈。真实文件上传、PDF 在线预览、OCR、正文索引、权限接口和版本持久化仍待生产建设。
