# 迭代 01：机加工作业区生产底座

周期：2 周

## 目标

- 建立可运行的前后端工程与开发环境。
- 建立铸锻件分公司六个作业区组织模型。
- 完成用户、角色、数据权限的数据结构。
- 建立风险、巡检、隐患闭环的首版数据库。

## 第 1 周

1. 项目骨架、Flyway、MySQL、MinIO。
2. 登录方案与组织权限接口。
3. 确认机加工作业区风险台账字段。
4. 收集一张真实巡检表并完成字段映射。

## 第 2 周

1. 用户、角色、组织管理页面与接口。
2. 风险台账列表、新增、编辑和停用。
3. 数据权限与操作日志。
4. 演示、问题收敛和迭代验收。

## 业务侧必须提供

- 机加工作业区组织和人员清单。
- 现行危险源台账。
- 至少一张日常/专项巡检表。
- 隐患整改与复查责任规则。

## 完成标准

- 新环境可按文档启动。
- 数据库迁移可重复执行。
- 普通用户只能查询授权作业区数据。
- 风险台账增改查留有操作日志。
